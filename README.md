# VibeVPN

Клиенты VibeVPN: для Android и для компьютера. Сервисная часть —
подписки, выдача ключей, оплата — живёт отдельно и сюда не входит.

Сайт и сборки: [vv.t-forge.online](https://vv.t-forge.online)

## Что внутри

| Папка | Что это |
|---|---|
| `android/` | Приложение для Android. Форк [v2rayNG](https://github.com/2dust/v2rayNG) под свои задачи: вход сканированием QR вместо ввода ссылок, свой бэкенд подписки, продление и поддержка прямо в приложении. |
| `desktop/` | Настольная версия для Windows и Ubuntu. Своя, на Go: интерфейс — локальная страница, ядро — xray, трафик ловится системным прокси или туннелем. |

Общее у них одно: ядро [Xray](https://github.com/XTLS/Xray-core) и
правила маршрутизации, которые приходят с сервера, — поэтому «российские
сервисы напрямую» работают одинаково на телефоне и на компьютере.

## Чем отличается от обычного клиента

Ссылку на подписку вводить не нужно. Телефон при первом запуске
получает её сам, компьютер — показывает QR, который сканируют телефоном,
где подписка уже есть. Продление и переписка с поддержкой встроены в
приложение.

## Сборка

Android:

```bash
cd android
BRAND=proxyvv ABI=universal ./build.sh
```

Нужны JDK 21, Android SDK и NDK. Ядро xray (`libv2ray.aar`) скрипт
скачивает сам, версия записана в `core.version`.

Компьютер:

```bash
cd desktop
./pack.sh          # vv-windows.zip и vv.deb
./pack.sh deb      # только Ubuntu
./pack.sh win      # только Windows
```

Нужен Go. Ядро, туннель и справочники `pack.sh` скачивает из релизов,
установщик для Windows собирает NSIS — его берёт из образа, ставить на
машину ничего не нужно.

Подробности — в `android/README.md` и `desktop/README.md`.
